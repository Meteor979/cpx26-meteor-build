# Design and Submission Assets

Owner: visual and communication owner.

Suggested structure:

```text
ui/               Interface specifications and screens
poster/amd-raw/   Raw unedited AMD-generated image
poster/amd-proof/ AMD Creative Factory Gallery screenshot
poster/final/     Final poster PDF and project image
assets/           Licensed source assets and provenance notes
```

Use team-owned or clearly licensed assets. Do not use celebrity photos or e-commerce product images without permission.
