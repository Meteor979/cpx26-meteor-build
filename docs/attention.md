# Project Attention List

## Competition rules

- Exactly four team members.
- All project work occurs during November 21-22, 2026.
- Disclose third-party APIs, open-source libraries, and AI tools.
- Publish the source repository under the Apache License 2.0.
- Submit by 13:00 Beijing time on November 22, 2026.

## Security

- Never commit API keys, `.env`, certificates, or personal data.
- Keep API keys on the backend only.
- Keep garment originals local. Send only temporary compressed images for explicit analysis and send metadata only for recommendations.
- Do not save team credentials permanently on the borrowed Mac.

## Demo

- Provide a reachable demo or prototype link.
- Test the link from another device and while signed out.
- Keep a mock and fallback path for network or AI failures.

## Mac

- Complete Xcode and Simulator setup before the event.
- Confirm the computer owner can unlock or authorize the machine when needed.
- Keep the Mac charging and ensure the owner remains reachable.

## Poster

## Feature freeze

After 09:00 on November 22, 2026, only fix build, demo, or submission blockers.
